┌──────────────────────────────────────────────────────────────────────────────┐
│                            💡 EXEMPLES D'UTILISATION                         │
└──────────────────────────────────────────────────────────────────────────────┘

  1️⃣  MONTER ET EXPLORER UN DISQUE USB
      ─────────────────────────────────
      • Brancher le disque USB
      • Cliquer sur "🔄 Rafraîchir"
      • Sélectionner "Lecture-écriture"
      • Cliquer sur "Monter"
      • Cliquer sur "Explorer"
      → L'explorateur s'ouvre sur le disque

  2️⃣  TROUVER LES GROS FICHIERS
      ──────────────────────────
      • Dans l'explorateur, cliquer sur l'en-tête "Taille"
      • Les fichiers sont triés par taille décroissante
      • Double-cliquer pour voir les détails
      → Identifiez rapidement les fichiers volumineux

  3️⃣  SURVEILLER UN PROCESSUS
      ────────────────────────
      • Aller dans l'onglet "⚙️ Processus"
      • Utiliser la recherche pour trouver le processus
      • Clic droit → "ℹ️ Détails" pour voir toutes les infos
      • Observer l'utilisation CPU/RAM en temps réel
      → Surveillance complète du processus

  4️⃣  VÉRIFIER LES PERMISSIONS
      ─────────────────────────
      • Naviguer vers le fichier dans l'explorateur
      • Consulter la colonne "Permissions"
      • Double-cliquer pour voir tous les détails
      • Vérifier propriétaire et groupe
      → Audit complet des droits d'accès

┌──────────────────────────────────────────────────────────────────────────────┐
│                              ⚠️ NOTES IMPORTANTES                            │
└──────────────────────────────────────────────────────────────────────────────┘

  🔒 PRIVILÈGES SUDO
     Le montage/démontage de disques nécessite sudo.
     Vous serez invité à entrer votre mot de passe.

  🔐 ACCÈS AUX FICHIERS
     Certains dossiers système nécessitent des privilèges root.
     Un message d'avertissement s'affiche si l'accès est refusé.

  ⚙️ PROCESSUS SYSTÈME
     Soyez prudent en terminant des processus.
     Ne terminez jamais de processus système critiques.

  🚀 PERFORMANCE
     • Analyse de gros disques : peut prendre du temps
     • Processus : limité à 200 pour les performances
     • Actualisation automatique : toutes les 3 secondes
